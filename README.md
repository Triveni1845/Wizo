# Wizo | Prompt Engineering Project

## Project Overview

Wizo is a beginner-friendly Python project developed
as part of the Wizori Prompt Engineering learning journey.

The application helps users transform simple prompts
into more structured and detailed instructions.

## Features

- Accepts prompts from users.
- Improves prompt structure using a predefined template.
- Adds clear instructions and context.
- Displays the improved prompt.
- Runs directly in the terminal.

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## How to Run the Project

1. Clone the repository:

   git clone https://github.com/Triveni1845/Wizo.git

2. Open the project folder:

   cd Wizo

3. Run the application:

   python main.py
